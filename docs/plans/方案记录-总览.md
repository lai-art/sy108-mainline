### 2.3 明确否决 ❌

| 方案 | 否决理由 |
|---|---|
| 基带独立热复位 | `modem_stop()` `-EOPNOTSUPP` + wwan 端口销毁会让 `udx-cellulard` 读 EOF 退出且 procd respawn 关闭；复位成功也可能需断电 |
| 前端 C 彻底重做 | 主张新建的 task-runner 已存在于 `udx.js:48` |
| A2 直接部署 FlowLoss | 浏览器端，测的是端到端链路；用户已拍板 B |
| "按权限渲染按钮" | 当前 ACL 是单一域，没有可判定能力位，会退化成"人人可见/人人不可见"假象 |
| 测速做上行 / 定时任务 / TURN 丢包 / AIM 评分 | 上行缺可写端点；定时任务半夜跑光流量；后两者超出设备定位 |
| 前端把"结果未知"当普通红字 | 会诱导用户重复操作，而 `CELL_UNCERTAIN` 明确不自动重放 |

> 🔒 **每次推送 / 触发 CI 构建前，必须单独通知用户并取得确认。**
